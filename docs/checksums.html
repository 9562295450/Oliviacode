The macOS and Linux artifacts were built on clean runners from the same tagged commit (9ae61f76) that produced the installer, and each runner built its own engine from that commit. Every platform also booted its own packed app on a profile that had never run before, so an install that cannot paint its shell fails the workflow instead of the user. SHA256SUMS.txt lists every asset except itself, taken from GitHub's stored digest for each upload.

The installer is not code-signed. The application binary's hash is different from the installer's on purpose: the installer is an NSIS container and the executable is one file inside it. Oliviacode is not affiliated with OpenCode or any provider named in a preset or community registry.
